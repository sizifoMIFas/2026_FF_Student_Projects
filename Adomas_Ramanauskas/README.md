## Data

- **Dataset:** Archigos 4.1, a database of political leaders (1875–2015)
- **Source:** http://ksgleditsch.com/data/1March_Archigos_4.1.txt (page: ksgleditsch.com/archigos.html)
- **Downloaded:** 11 November 2026
- **File:** `data/raw/Archigos_4.1.txt`, 672,850 bytes
- **MD5:** 9cb7d50e8dc52f8d0740c04bda8f370c
- **Format:** tab-separated text, one row per leader term
- **Licence:** no licence statement found; check the Archigos page before redistributing
- **Citation:** Goemans, H. E., Gleditsch, K. S., & Chiozza, G. (2009). Introducing Archigos: A Dataset of Political Leaders. *Journal of Peace Research*, 46(2), 269–283.

## Folders

- `data/raw/`: the original download, never edited
- `data/processed/`: tables written by scripts
- `scripts/`: one script per step
- `results/`: figures and numbers written by scripts
